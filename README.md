# My Virtual Employee - AI Agents Website

Welcome to the My Virtual Employee website repository. This site showcases our AI-powered virtual employee service featuring specialized agents for various business functions.

## 🚀 Features

- **5 Specialized AI Agents**:
  - **James** - Researcher: Finds prospect emails & phone numbers
  - **Alex** - Cold Caller/Setter: Makes outbound calls and books appointments
  - **Maya** - Inbound Sales: Handles incoming calls 24/7
  - **Ian** - Data Engineer: Processes and analyzes data
  - **Tiffany** - Customer Service: Provides round-the-clock support

- **Interactive Elements**:
  - Animated network visualization
  - Responsive design for all devices
  - Live chat interface with Daniel (AI Assistant)
  - Smooth scroll animations
  - Modern gradient effects
